# sshrm
Tool to connect via ssh without the "REMOTE HOST IDENTIFICATION HAS CHANGED" error

## Usage
Same usage as the original ssh command

Exemples :
```
sshrm user@192.168.1.2
sshrm 192.168.1.2 -p 2222
```

## Installation
Download the files, extract them and :

```
make install
```

## Uninstall
```
make uninstall
```
